FitzHugh-Nagumo model

Consider the FHN system: \[ \left\{\begin{aligned} \varepsilon v' &= f(v) - w + I_\text{app}, \\ w' &= v - \gamma w, \end{aligned}\right. \]

with \(f(v) = v(1-v)(v-\alpha)\) and \(I_\text{app} \in \mathbb{R}\). We assume that \(\varepsilon \ll 1\), so that we can always apply the singular perturbation analysis.

  1. Show that for \(I_\text{app}>0\) constant and sufficiently large (but not too large), the system has a (singular) limit cycle. Provide a formula for the period.
Solution

First notice that when \(I_\text{app}\) is sufficiently large, the (unique) equilibrium \((\bar{v},\bar{w})\) becomes unstable, \[ J = \begin{pmatrix} \varepsilon^{-1}f'(v) & -\varepsilon^{-1} \\ 1 & -\gamma \end{pmatrix} \]

because the trace \(\operatorname{tr}J = \varepsilon^{-1}f'(\bar{v}) - \gamma\) will become positive when \(f'(\bar{v})>\varepsilon\gamma\). Therefore, there is the opportunity for a limit cycle to appear (this can be shown with a trapping region).

The analysis is the same as the one seen in class.

The fast system reads: \[ \left\{\begin{aligned} \dot{v} &= f(v) - w + I_\text{app}, \\ \dot{w} &= \varepsilon (v - \gamma w). \end{aligned}\right. \]

In the singular limit, \(\varepsilon \to 0\), the system reduces to: \[ \left\{\begin{aligned} \dot{v} &= f(v) - w + I_\text{app}, \\ \dot{w} &= 0, \end{aligned}\right. \]

so \(w=w_0\). The first equation has up to three equilibria, two stable branches \(V_{\pm}(w_0)\) and one unstable \(V_0(w_0)\) such that \[ f(V_{\pm,0}(w_0)) - w_0 + I_\text{app} = 0. \]

The existence the branches depends on \(w_0\), \(V_+\) exists for \(w_0 < w^*\) and \(V_-\) exists for \(w_0 > w_*\) and \(V_0\) for \(w_* < w_0 < w^*\), where \(w_*\) and \(w^*\) are local min and max of \(f(v)+I_\text{app}\).

In the slow system, assuming \(v\) is at equilibrium, we have the following dynamic for \(w\) \[ w' = V_{\pm}(w) - \gamma w. \tag{1}\]

If the equilibrium of the system is such that \(w_* < \bar{w} < w^*\), then we have a singular limit cycle. This can be seen from Figure 13.1, if we follow the path from the initial condition, we first have a fast branch from \((v_0,w_0)\) to \((V_+(w_0),w_0)\), then we continue as follows: \[ (V_+(w_0),w_0) \leadsto (V_+(w^*),w^*) \leadsto (V_-(w^*),w^*) \leadsto (V_-(w_*),w_*) \leadsto \cdots \]

We can estimate the period from Equation 1: \[ T = t_e + t_r = \int_{w_*}^{w^*} \Bigl( \frac{1}{V_+(w)-w} - \frac{1}{V_-(w)-w} \Bigr) \mathrm{d}w, \]

where \(t_e\) and \(t_r\) are respectively the excited and recovery time.

  1. Try to sketch the bifurcation diagram with respect to \(I_\text{app}\), mentioning all bifurcations.
Solution

We have two Hopf bifurcations, for \(I_\text{app}\) such that \(\bar{w}=w_*\) or \(\bar{w}=w^*\). In the range \(w_* < \bar{w} < w^*\) we have a limit cycle, that is attractive. The equilibrium \((\bar{v},\bar{w})\) is stable outside this range and unstable when the limit cycle is present.

  1. Anode break excitation is when the potential is slowly decreased (thus, \(I_\text{app}\) is negative rather than positive) and then switched off. Can we trigger an action potential in this way? Does it work also when the application time of the current is short?
Solution

Yes, it works. If we switch on the current \(v\) starts to decrease, but since it is slow, we follow the equilibrium of the system. If we apply the current for sufficiently long time to bring \(\bar{w}\) below \(w_*\), then when we switch off the current the fast dynamics will bring this new initial condition to the stable branch \(V_+(w)\), triggering an action potential. So, it’s not the magnitude that matters, but the time of application of the current.

When we apply a strong negative current for short time, the system will first go (fast dynamics) to \((V_-(0),0)\), and then back to \((0,0)\) when the current is switched off. However, if we keep the current on, the slow dynamic will be present following \(V_-(w)\) for negative \(w\), because \(w'<0\). If we wait enough time (try to estimate it), then we can trigger the action potential.

Roger-McCulloch model

Consider the Roger-McCulloch system: \[ \left\{\begin{aligned} \varepsilon v' &= -kv(v-\alpha)(v-1) - vw + I_\text{app}, \\ w' &= v - \gamma w, \end{aligned}\right. \]

Suppose \(\varepsilon \ll 1\). The parameters have the same meaning as in the FitzHugh-Nagumo system.

  1. Consider \(I_\text{app}=0\). Study the phase portrait and show how an action potential may occur.
Solution

This system is a very minor modification of the previous one, and the dynamics is similar. The only difference is the fast subsystem: \[ \dot{v} = -kv(v-\alpha)(v-1) - v w_0 = F(v) \]

and the equilibria are \(v_0=0\) and the roots of \(k(v-\alpha)(v-1)+w_0=0\). For \(w_0 < w^*\) we always have 2 roots, \(v_1(w_0) < v_2(w_0)\).

For the stability, we have that \(v_0\) and \(v_1(w_0)\) are stable, while \(v_2(w_0)\) is unstable, unless \(w < w_* = -k\alpha\). For \(w=w_*\) there is a swap of stability between \(v_0\) and \(v_1\). Therefore, we can define

  • \(V_-(w) = 0\) for \(w > w_*\) and \(V_-(w) = v_1(w)\) for \(w < w_*\);
  • \(V_0(w) = v_1(w)\) for \(w_* < w < w^*\) and \(V_0(w) = 0\) for \(w < w_*\);
  • \(V_+(w) = v_2(w)\) for \(w < w^*\).

With this definition, the theory is the same as before. To trigger an action potential, we need to start with \(v>0\) and \(w < k(v-\alpha)(v-1)\).

  1. What does it happen when \(I_\text{app}\neq 0\)? Is the situation similar to the previous exercise?
Solution

We can check graphically that this is not the case, we cannot have a limit cycle. For \(I_\text{app}\neq 0\), the \(v\)-nullcline is cubic-like for small \(I_\text{app}\), but then it loses the bistability before we could mimic a situation like in the previous exercise. However, it is not simple to prove analytically.

Hodgkin-Huxley model

When using the voltage-clamp technique, the total transmembrane current can be accurately measured. However, Hodgkin and Huxley were interested in the individual sodium \(I_{\ce{Na}}\) and potassium \(I_{\ce{K}}\) currents. How can we estimate them from \(I_\text{tot} = I_{\ce{Na}} + I_{\ce{K}}\)? This exercise addresses the question.

  1. Are there potential levels (fixed by clamping) at which we can measure a pure \(I_{\ce{Na}}\) or \(I_{\ce{K}}\) current?
Solution

Yes, at the Nernst potentials. When \(V=V_{\ce{Na}}\), \(I_{\ce{Na}} = 0\) so \(I_\text{tot} = I_{\ce{K}}\), and when \(V=V_{\ce{K}}\), \(I_{\ce{K}}=0\) so \(I_\text{tot} = I_{\ce{Na}}\). Of course, in this case we only get the current for a specific value of \(V\), and not for all values, so we cannot use it to determine the gating dynamics.

  1. Suppose 90% of the \(\ce{Na+}\) in the bath of a squid axon is replaced by inert choline, preserving electroneutrality. What happens to the equilibrium potentials?
Solution

Only \(V_{\ce{Na}}\) is affected. From the Nernst equation: \[ V^1_{\ce{Na}} = \frac{RT}{zF}\ln\frac{\ce{[Na+]^1_e}}{\ce{[Na+]^1_i}} \]

where we use “1” to reference quantities (no choline).

If w replace 90% of the extracellular sodium, then \(\ce{[Na+]^2_e} = 0.1\ce{[Na+]^1_e}\) and \(\ce{[Na+]^1_i}=\ce{[Na+]^2_i}\) so we have: \[ \begin{split} V^2_{\ce{Na}} &= \frac{RT}{zF}\ln\frac{\ce{[Na+]^2_e}}{\ce{[Na+]^2_i}} \\ &= \frac{RT}{zF}\ln\frac{0.1\ce{[Na+]^1_e}}{\ce{[Na+]^1_i}} \\ &= V^1_{\ce{Na}} - \frac{RT}{zF}\ln 10 \end{split} \]

With the actual numbers (see the Table 12.1), \(V^2_{\ce{Na}} \approx -3.48\,\text{mV}\).

  1. Explain why replacing the extracellular \(\ce{Na+}\) with choline has little effect on the resting potential of an axon. Calculate the new resting potential with 90% of the extracellular \(\ce{Na+}\) removed. Why is the same not true if \(\ce{K+}\) is replaced? Assume \(m = 0.0532\), \(n = 0.3184\), \(h=0.5945\) (constants), \(\bar{g}_{\ce{Na}} = 120\,\text{mS}\), \(\bar{g}_{\ce{K}} = 36\,\text{mS}\), \(\bar{g}_\text{leak} =0.3\,\text{mS}\), \(V_\text{leak} = -54.4\,\text{mV}\) and \(V_{\ce{K}} = -77.3\,\text{mV}\).
Solution

Using the formula: \[ V_\text{eq} = \frac{g_{\ce{Na}}V_{\ce{Na}}+g_{\ce{K}}V_{\ce{K}}+g_l V_l}{g_{\ce{Na}}+g_{\ce{K}}+g_l} \]

with \(g_{\ce{Na}} = \bar{g}_{\ce{Na}} m^3 h\), \(g_{\ce{K}} = \bar{g}_{\ce{K}} n^4\). With \(V_{\ce{Na}} = V_{\ce{Na}}^1\) we obtain \(V^1_\text{eq} \approx -65\,\text{mV}\), with \(V_{\ce{Na}}^2\) we have \(V^2_\text{eq} \approx -66\,\text{mV}\).

The reason is that while \(V_{\ce{Na}}\) changes significantly, most of the channels are closed because \(m\approx 0\), so they contribute little to the resting membrane potential.

If we change the extracellular \(\ce{K+}\), then \(V^2_{\ce{K}} \approx -136\,\text{mV}\) and the new resting membrane potential would be \(V^2_\text{rest}\approx -136\,\text{mV}\). In fact, \(n\neq 0\), so potassium channels contribute the most to the resting membrane potential.

  1. Suppose we know \(K = I^1_{\ce{Na}}/I^2_{\ce{Na}}\), where \(I^1_{\ce{Na}}\) is the normal sodium current and \(I^2_{\ce{Na}}\) is the one obtained with 90% of extracellular sodium replaced by choline. Suppose also that \(K\) does not change over time and \(I^1_{\ce{K}}=I^2_{\ce{K}}\). Find \(I^1_{\ce{Na}}\) and \(I^2_{\ce{Na}}\) from \(I^1_\text{tot}\) and \(I^2_\text{tot}\). (A possible way to measure \(K\) is to look at \(I_{\ce{tot}}\) immediately after the voltage clamp, because most of the initial current is carried by sodium.)
Solution

Since \(I^1_\text{tot} = I^1_{\ce{Na}} + I^1\ce{K}\) and \(I^2_\text{tot} = I^2_{\ce{Na}} + I^2\ce{K}\), we solve the system: \[ \begin{aligned} I^1_\text{tot} &= I^1_{\ce{Na}} + I^1\ce{K}, \\ I^2_\text{tot} &= 1/K I^1_{\ce{Na}} + I^1\ce{K}. \end{aligned} \]

The solution is: \[ \begin{aligned} I^1_{\ce{Na}} &= \frac{K}{1-K}(I^2_\text{tot} - I^1_\text{tot}), \\ I^1_{\ce{K}} &= \frac{KI^2_\text{tot}- I^1_\text{tot}}{1-K}. \end{aligned} \]

  1. Nowadays a simpler way to block channels is with drugs. Tetrodotoxin (TTX) is a powerful neurotoxin, famous for the puffer fish. TTX acts by blocking the sodium channels, hence making them unavailable for action potential formation.

    Here is how we can model it. If \(P_0\) represents the total number of \(\ce{Na+}\) channels, and we denote by \(\ce{P}\) and \(\ce{B}\) respectively the number of non-blocked and blocked channels, then the reaction is \[ \ce{P + TTX <=>[k_{-1}][k_1] B}. \]

    Modify the sodium conductance to account for the presence of .

Solution

With the quasi-equilibrium approximation, knowing that \(\ce{[P]}+\ce{[B]}=\ce{[P]_0}\), we have: \[ \frac{P}{P_0} = \frac{1}{1 + \ce{TTX}/K_1}. \]

where \(K_1 = \frac{k_{-1}}{k_1}\).

The maximum sodium conductance is proportional to the number of available channels. Hence, \[ \bar{g}_{\ce{Na}}(\ce{TTX}) = \frac{\bar{g}^\text{max}_{\ce{Na}}}{1 + \ce{TTX}/K_1}. \]

Gating mechanism

A ion channel can be modelled with a Markov model. For instance, for a channel we have the following state diagram:

Here we want to show that the probability of the state \(I_2\) is exactly \(n^2(t)\), where: \[ \frac{\mathrm{d}n}{\mathrm{d}t} = \alpha (1-n) - \beta n. \]

  1. Write down the equations of the system, where \(s_k(t)=\mathbb{P}[\text{state is $I_k$}]\), with \(k=0,1,2\). Observe that \(s_0(t) + s_1(t) + s_2(t) = 1\).
Solution

The system is:

\[ \left\{\begin{aligned} s_0' &= -2\alpha s_0 + \beta s_1, \\ s_1' &= 2\alpha s_0 - \beta s_1 - \alpha s_1 + 2\beta s_2, \\ s_2' &= \alpha s_1 - 2\beta s_2. \end{aligned}\right. \]

Note that \(s_0'+s_1'+s_2'=0\), so their sum is constant. Since their are probabilities, their sum is 1.

  1. Set \(s_0(t)=(1-n)^2\), \(s_1(t)=2n(1-n)\), \(s_2(t)=n^2\), with \(n(t)\) solution of the above ODE. Show that this choice provides a solution of the full system.
Solution

First, compute the derivatives of \(s_0(t)\), \(s_1(t)\), and \(s_2(t)\):

\[ \begin{aligned} s_0' &= 2(1-n)(-n'), \\ s_1' &= 2(1-2n)(n'), \\ s_2' &= 2n(n'). \end{aligned} \]

Now, substitute these into the system of equations:

\[ \begin{aligned} -2(1-n) n' &= -2\alpha (1-n)^2 + \beta 2n(1-n), \\ 2(1-2n) n' &= 2\alpha (1-n)^2 - \beta \cdot 2n(1-n) - \alpha \cdot 2n(1-n) + 2\beta n^2, \\ 2n n' &= \alpha \cdot 2n(1-n) - 2\beta n^2. \end{aligned} \]

Simplify each equation to verify that all sides correspond to the same equation \[ n' = \alpha(1-n) - \beta n. \]

  1. Try to generalize to a system with \(k+1\) states, showing that the ODE is always the same with the probability of \(I_k\) being \(n^k(t)\).
Solution

The diagram will look like this

The \(j\)-th state satisfies \[ s_j' = (k-j+1)\alpha s_{j-1} - (k-j)\alpha s_j - j \beta s_j + (j+1)\beta s_{j+1}. \tag{2}\]

Of course we assume that \(s_{-1}\) and \(s_{k+1}\) do not appear in the equations for \(j=0\) and \(j=k\).

Now set \[ s_j=\binom{k}{j} n^j (1-n)^{k-j}, \]

with \(n\) solution of the ODE \(n' = \alpha (1-n) - \beta n\). Note that \(s_k = n^k\).

We compute the derivative: \[ s_j' = \binom{k}{j} \left[ j n^{j-1} (1-n)^{k-j} - (k-j) n^j (1-n)^{k-j-1} \right] n', \]

which should match the right hand side of Equation 2. Note that: \[ \begin{aligned} s_{j-1} &= \binom{k}{j-1} n^{j-1} (1-n)^{k-j+1} = \binom{k}{j} \frac{j}{k-j+1} n^{j-1} (1-n)^{k-j+1}, \\ s_{j+1} &= \binom{k}{j+1} n^{j+1} (1-n)^{k-j-1} = \binom{k}{j} \frac{k-j}{j+1} n^{j+1} (1-n)^{k-j-1}. \end{aligned} \]

In fact substituting into Equation 2 yields: \[ \begin{split} s_j' &= \binom{k}{j} \Bigl[ \alpha(1-n) \bigl( jn^{j-1} (1-n)^{k-j} - (k-j)n^j (1-n)^{k-j-1} \bigr) \\ &- \beta n \bigl( j n^{j-1} (1-n)^{k-j} - (k-j)n^{j} (1-n)^{k-j-1} \bigr) \Bigr] \\ &= \binom{k}{j} \bigl( jn^{j-1} (1-n)^{k-j} - (k-j)n^j (1-n)^{k-j-1} \bigr) \bigl( \alpha(1-n) - \beta n \bigr). \end{split} \]

Multidimensional fronts

In excitable media like the cardiac tissue, the cable equation generalises to its multidimensional version: \[ \varepsilon \frac{\partial V}{\partial t} = \varepsilon^2 \Delta V + f(V). \]

where \(\Delta\) is the Laplacian, that is for \(x = (x_1,x_2,\ldots,x_n)\in\mathbb{R}^n\) we have: \[ \Delta V = \frac{\partial^2 V}{\partial x_1^2} + \frac{\partial^2 V}{\partial x_2^2} + \cdot + \frac{\partial^2 V}{\partial x_n^2}. \]

  1. Show that a planar wave, that is \(V(x,t) = U(\frac{x\cdot\vec{k}+st}{\varepsilon})\) with \(\vec{k}\) the unit vector pointing in the propagation direction, one has exactly the 1-D result for the velocity: \[ s = \frac{1}{\sqrt{2}}(2\alpha-1). \]
Solution

For convenience we set \[ \xi = \frac{x \cdot \vec{k} + st}{\varepsilon}. \]

We start by substituting the planar wave solution into the multidimensional cable equation: \[ \begin{aligned} \frac{\partial V}{\partial t} &= \frac{s}{\varepsilon} U'(\xi), \\ \frac{\partial V^2}{\partial x_i^2} &= \frac{k_i^2}{\varepsilon^2} U''(\xi). \end{aligned} \]

Summing over all spatial dimensions, we get: \[ \Delta V = \frac{1}{\varepsilon^2} U''(\xi) \]

since \(\vec{k}\) is a unit vector, so \(\sum_i k_i^2 = 1\). Substituting these into the cable equation, we obtain: \[ \varepsilon \frac{s}{\varepsilon} U' = \varepsilon^2 \frac{1}{\varepsilon^2} U'' + f(U), \]

which simplifies to: \[ s U' = U'' + f(U). \]

This is exactly the same as the 1-D cable equation. Therefore, the speed of the planar wave is: \[ s = \frac{1}{\sqrt{2}}(2\alpha - 1). \]

  1. Consider now a spherical front, that is \(V(x,t) = U(\frac{|x| + st}{\varepsilon}) = U(r + st)\) where \(r=|x|\) is the radius of the sphere. Using the fast system, show that the speed is as follows: \[ s = s_0 - \kappa \varepsilon, \]

    where \(s_0\) is the speed of a planar front and \(\kappa = \frac{n-1}{r}\) is the curvature of the front. Show that, compared to a planar front, the velocity of a concave front is larger and for a convex front is lower.

Solution

Proceeding as before, we set \[ \xi = \frac{r + st}{\varepsilon}. \]

Note that: \[ \begin{aligned} r &= \sqrt{\sum_i x_i^2}, \\ \frac{\partial r}{\partial x_i} &= \frac{x_i}{\sqrt{\sum_i x_i^2}} = \frac{x_i}{r}. \end{aligned} \]

Substituting into the cable equation we have: \[ \begin{aligned} \frac{\partial V}{\partial t} &= \frac{s}{\varepsilon} U'(\xi), \\ \frac{\partial V}{\partial x_i} &= \frac{1}{\varepsilon} U'(\xi) \frac{\partial r}{\partial x_i} = \frac{x_i}{\varepsilon r} U'(\xi), \\ \frac{\partial^2 V}{\partial x_i^2} &= \frac{x_i}{\varepsilon^2 r} U''(\xi) \frac{\partial r}{\partial x_i} + \frac{\partial}{\partial x_i} \Bigl( \frac{x_i}{\varepsilon r} \Bigr) U'(\xi) \\ &= \frac{x^2_i}{\varepsilon^2 r^2} U''(\xi) + \frac{r^2 - x_i^2 }{\varepsilon r^3} U'(\xi). \end{aligned} \]

The Laplacian in spherical coordinates is given by: \[ \begin{split} \Delta V &= \frac{\sum_i x^2_i}{\varepsilon^2 r^2} U''(\xi) + \sum_i \frac{r^2 - x_i^2}{\varepsilon r^3} U'(\xi) \\ &= \frac{1}{\varepsilon^2} U''(\xi) + \frac{n - 1}{\varepsilon r} U'(\xi). \end{split} \]

Substituting these into the cable equation, we obtain: \[ s U' = U'' + \kappa \varepsilon U' + f(U), \]

where \(\kappa = \frac{n-1}{r}\). Rearranging terms, we get: \[ (s - \kappa \varepsilon) U' = U'' + f(U). \]

Therefore, the speed of the spherical front is: \[ s = s_0 - \kappa \varepsilon, \]

where \(s_0\) is the speed of a planar front.

Compared to a planar front, the velocity of a concave front (negative curvature) is larger, and for a convex front (positive curvature) is lower.

Remark. The above derivation is not entirely correct. We should perform a complete perturbation analysis. In fact, in the fast coordinate \(\xi\), when we set \(\varepsilon\to 0\) the curvature effect disappears.

The correct analysis is much more complicated, we report it here for completeness. We assume that \[ \begin{aligned} U(\xi) &= U_0(\xi) + \varepsilon U_1(\xi) + \varepsilon^2 U_2(\xi) + \cdots, \\ s &= s_0 + \varepsilon s_1 + \varepsilon^2 s_2 + \cdots, \end{aligned} \]

then we substitute into the equation: \[ s_0 U_0 + \varepsilon (s_1 U'_0 + s_0 U_1') + \cdots = U_0'' + \varepsilon U_1'' + \kappa \varepsilon U_0' + f(U_0) + \varepsilon f'(U_0) U_1 + \cdots. \]

The polynomial in \(\varepsilon\) is zero when each coefficient is zero, that is, \[ \begin{aligned} &\mathcal{O}(1) && s_0 U_0 = U_0'' + f(U_0), \\ &\mathcal{O}(\varepsilon) && s_1 U'_0 + s_0 U_1' = U_1'' + \kappa U_0' + f'(U_0) U_1. \end{aligned} \]

The \(\mathcal{O}(1)\) yields the planar wave solution, with \(s_0\) as in the previous point and \(U_0(\xi)\) the \(\tanh\) solution.

The \(\mathcal{O}(\varepsilon)\) is a linear ODE of the form: \[ \mathcal{L}[U_1] = s_0 U_1' - U_1'' - f'(U_0) U_1 = - s_1 U'_0 + \kappa U_0', \]

where \(\mathcal{L}[U_1]\) is a second-order (linear) differential operator. This operator is singular, that is there exists a non-trivial solution \(U_1\) such that \(\mathcal{L}[U_1] = 0\). This function is \(U_0'\), in fact \[ \mathcal{L}[U'_0] = s_0 U_0'' - U_0''' - f'(U_0)U_0' = [s_0 U_0' - U_0'' - f(U_0)]' = 0. \]

Therefore, the linear ODE has solutions only if the right hand side is orthogonal to the range of the adjoint operator \(\mathcal{L}^*\). (Think of a linear system \(Ax=b\). When \(A\) is non-singular, the system has a unique solution for every \(b\). When \(A\) is singular, the system has either no or an infinite number solutions, depending on \(b\). If \(b\) is in the range of \(A\), then we have an infinite number. But \(b\) in the range of \(A\) means \(b\cdot w\) for any \(w\) in the kernel of \(A^T\).)

The adjoint operator is: \[ \mathcal{L}^*[w] = -s_0 w' - w'' - f'(U_0) w. \]

The function \(w = e^{-s_0 \xi}U_0'\) is in the kernel of \(\mathcal{L}^*\). The orthogonality condition reads: \[ \int_{-\infty}^{\infty} w(\xi)(- s_1 U'_0 + \kappa U_0')\,\mathrm{d}\xi = 0. \]

Therefore we have: \[ (\kappa-s_1) \int_{-\infty}^{\infty} e^{-s_0 \xi}(U_0')^2\,\mathrm{d}\xi = 0. \]

Since the integral is strictly positive, we must have \(s_1=\kappa\) and therefore: \[ s = s_0 + \kappa \varepsilon + \cdots \]
