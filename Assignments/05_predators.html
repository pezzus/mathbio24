Existence of cycles

Consider the following competition model: \[ \left\{\begin{aligned} N_1' &= r_1 N_1 (1 - N_1/K_1) - b_1 N_1 N_2, \\ N_2' &= r_2 N_2 (1 - N_2/K_2) - b_2 N_1 N_2, \end{aligned}\right. \]

where \(N_1(t)\) and \(N_2(t)\) are two species. (The modeling details are unimportant now.) Show that the system has no periodic orbits. All parameters are positive. Hint: use the function \(h(N_1,N_2)=1/(N_1 N_2)\) in the Dulac’s criterium.

Solution

We need to compute the divergence of \(h\mathbf{f}\), and check whether the sign is constant: \[ \begin{split} \nabla\cdot(h\mathbf{f}) &= \frac{\partial}{\partial N_1}\Bigl( r_1 \frac{1 - N_1/K_1}{N_2} - b_1 \Bigr) + \frac{\partial}{\partial N_2}\Bigl( r_2 \frac{1 - N_2/K_2}{N_1} - b_2 \Bigr) \\ &= - \frac{r_1}{K_1 N_2} - \frac{r_2}{K_2 N_1} < 0 \end{split} \]

in the first quadrant. Thus, there cannot be limit cycles.

Leslie model

Leslie (1948) proposed the following system as a model for the predator-prey dynamics: \[ \left\{\begin{aligned} H' &= H (a - bH -cP), \\ P' &= P (r - s P/H ). \end{aligned}\right. \]

In other words, the predators \(P\) have a logistic type dynamics with carrying capacity proportional to the density of preys \(H\).

  1. State clearly, and in case criticize, the assumptions of the model.
Solution

The predator equation follows a logistic growth, with carrying capacity \(K_p = r H/s\), thus proportional to the prey population. The prey population has a logistic growth as well, with carrying capacity \(K_h = a/b\), and a linear hunting term with attack rate \(c\). This last point is unrealistic, but more importantly the growth rate of the predators is unbounded for \(H\to 0^+\).

  1. Draw the isoclines in the phase plane, and find the positive equilibrium.
Solution

Both nullclines are straight lines. Besides the equilibrium \(E_K=(K_a,0)\), there is always an additional equilibrium \[ E_* = \Bigl(\frac{sa}{rc+bs}, \frac{ra}{rc+bs}\Bigr). \]

  1. Study its stability.
Solution

The Jacobian at the equilibrium is \[ J_* = \left[ \begin{matrix} -bH_* & -c H_* \\ r^2/s & -r \end{matrix} \right]. \]

We have: \[ \begin{aligned} \operatorname{tr}J_* &= -bH_*- r < 0, \\ \det J_* &= brH_* + cr^2/s H_* = ar > 0.\end{aligned} \]

So the point is always asymptotically stable.

Optimal hunting strategy

Consider the general Gause model with logistic growth rate \(r(H)\) and numerical response \(\omega(H)\) proportional to the functional response \(\pi(H)\), that is \(\omega(H) = \gamma \pi(H)\).

  1. Write down the model.
Solution

We have: \[ \left\{ \begin{aligned} H' &= r H(1-H/K) - \pi(H)P, \\ P' &= -\mu P + \gamma \pi(H)P.\end{aligned}\right. \]

  1. Consider \(\pi(H)\) linear, with attack rate \(a\ge0\). Compute the stable equilibrium population size of the predators.
Solution

The model reads: \[ \left\{ \begin{aligned} H' &= H (r(1-H/K) - a P), \\ P' &= P(-\mu + \gamma a H).\end{aligned}\right. \]

We can have 2 or 3 equilibria. Besides the trivial equilibrium \(E_0=(0,0)\), we have \(E_K=(K,0)\) and \(E^*=(H^*,P^*)\), with \(H^* = \frac{\mu}{\gamma a}\) and \(P^*=\frac{r}{a}(1-\frac{H^*}{K})\). The equilibrium \(E^*\) exists only when \(P^*\ge 0\).

Therefore we have: \[ P^*= \begin{cases} 0, & H^* \ge K, \\ \frac{r}{a}(1-\frac{H^*}{K}), & H^* < K. \end{cases} \]

  1. Now suppose that the predator species evolves over several generations, by adapting the value of \(a\), so to maximize its equilibrium size. Find the optimal value of \(a\).
Solution

We need to maximize the function \(P^*(a)\) from above. Let’s put \(1/a=\frac{\gamma H^*}{\mu}\), so we have: \[ P^*(H^*)=\frac{\gamma r H^*}{\mu} \Bigl(1- \frac{H^*}{K} \Bigr), \]

for \(H^*<K\), and zero otherwise. The function is maximized for \(H^*_\mathrm{opt}=\frac{K}{2}\), corresponding to: \[ a_\mathrm{opt} = \frac{\mu}{\gamma H^*_\mathrm{opt}} = \frac{2\mu}{\gamma K}. \]

  1. Repeat the previous point by assuming a Holling type 2 response.
Solution

The model in this case is \[ \left\{ \begin{aligned} H' &= H \Bigl(r(1-H/K) - \frac{a P}{1+a T_h H}\Bigr), \\ P' &= P\Bigr(-\mu + \gamma \frac{a H}{1+a T_h H}\Bigl).\end{aligned}\right. \]

As before, we have the equilibria \(E_0\) and \(E_1\). For \(E^*\) we have: \[ H^* = \frac{\mu}{a(\gamma - \mu T_h)}. \]

The condition is as above, \(H^*< K\) so to have \(E^*\).

The equilibrium value of \(P^*\) is \[ P^* = \frac{r}{a}(1-H^*/K)(1+a T_h H^*). \]

Now, \(a H^*= \frac{\mu}{\gamma - \mu T_h}\), and \(\frac{1}{a} = \frac{H^*(\gamma - \mu T_h)}{\mu}\), so \[ P^*(H^*) = \frac{r}{\mu}H^*(\gamma-\mu T_h)(1-H^*/K)\Bigl(1+\frac{\mu T_h}{\gamma-\mu T_h}\Bigr), \]

which again is maximized for \(H^*_\mathrm{opt} = \frac{K}{2}\) (it is a quadratic function of \(H^*\), the vertex is for \(H^*_\mathrm{opt}\)), corresponding to \(a_\mathrm{opt} = \frac{2 \mu}{K(\gamma-\mu T_h)}\). Note that this is consistent with the previous formula, with \(T_h=0\).

Juvenile predators

One feature not very realistic of standard predator-prey models is that predators start catching prey as soon as they are born. One way to circumvent this problem is to introduce a class of juvenile predators, say \(J(t)\), that do not catch prey; juveniles become adults at constant rate, say \(\rho\).

Taking all other assumption from the first model that has been presented, and assuming that death rate is the same for juvenile and adult predators, we arrive at the system \[ \begin{cases} H' = r (1−\frac{H}{K})H − aHP, & \\ J' = \gamma aHP − \rho J − \mu J, & \\ P' = \rho J - \mu P. & \end{cases} \]

  1. Read from the model, which is the probability that a newly born juvenile will still be a juvenile at time \(t\). And which is the probability that a newly born juvenile will still be a juvenile at time \(t\), conditional on being still alive at time \(t\)? From these computations, interpret the parameter \(\rho\).
Solution

The main ingredient for this question is the following fact. For the Malthus model \(N'=-\nu N\), the solution \(N(t)=N_0 e^{-\nu t}\) can be interpreted as a survival probability. Suppose that the random variable \(L \sim \operatorname{Exp}[\nu]\) represent the life duration, with probability density function \(\ell(t) = \nu e^{-\nu t}\). Then the survival probability up to age \(t\) is \(\mathbb{P}[L > t] = 1 - \mathbb{P}[L \le t] = e^{-\nu t}\), which is (up to a constant) the solution of the ODE. The average life duration is \(1/\nu\).

The answer to the first question is therefore \(e^{-(\rho+\mu) t}\), because the average time spent in the “compartment” \(J\) is \(\frac{1}{\rho+\mu}\).

Regarding the second question, we need consider only the term \(-\mu J\), which accounts for individual dying before becoming adults. So the answer is \(e^{-\mu t}\).

The interpretation of \(\rho\) is therefore the probability of being juvenile at time \(t\), conditional to not dying: \[ \mathbb{P}[\text{juvenile} | \text{die}] = \frac{e^{-(\rho+\mu)t}}{e^{-\mu t}} = e^{-\rho t} \]

In other words, \(\frac{1}{\rho}\) is the average juvenile period neglecting death.

  1. On the basis of the previous point discuss the realism of the assumption that juveniles become adults at constant rate (assumption necessary to frame the model in terms of ordinary differential equations). Suggest possible changes to the assumption.
Solution

Given the above observation, we can interpret the length of the juvenile period for those surviving as an exponential distribution with parameter \(\rho\). The distribution is not realistic, because the probability decreases with the length. A more realistic distribution would assume a peak probability around puberty, similar to a Gaussian. However this type of model cannot be captured by an ODE.

  1. Show that using appropriate changes of variables system can be written as \[ \begin{cases} x' = \sigma x(1-x) − \alpha x z, & \\ y' = \alpha x z − (\nu+1)y, & \\ z' = \nu y - z. & \end{cases} \]
Solution

One strategy is to assume a general rescaling of the form \[ x = \frac{H}{h},\quad y = \frac{J}{j},\quad z = \frac{P}{p},\quad s=\tau t. \]

Then we try to match the terms. We see that \[ h=K,\quad j=p=\gamma K,\quad \tau=\mu, \]

from which we can define the parameters of the model \[ \sigma = \frac{r}{\mu},\quad \alpha=\frac{a\gamma K}{\mu},\quad \nu=\frac{\rho}{\mu}. \]

  1. Show that the new system has always the equilibria \(E_0 = (0,0,0)\) and \(E_1 = (1, 0, 0)\). Find the conditions under which it has also a positive equilibrium \(E^+ = (x^+,y^+, z^+)\) and compute its coordinates.
Solution

We check the isoclines, which are \[ \begin{aligned} &x'=0,\quad\Leftrightarrow\quad x = 0, & z = \tfrac{\sigma}{\alpha}(1-x), \\ &y'=0,\quad\Leftrightarrow\quad y = \tfrac{\alpha}{1+\nu}xz, & \\ &z'=0,\quad\Leftrightarrow\quad z = \nu y. & \end{aligned} \]

We see that \(E_0=(0,0,0)\) and \(E_1=(1,0,0)\) are both equilibria. The third one we find by substituting \(y = \nu z\) into the isocline for \(y'=0\). This leads to \(\bar x=\frac{\nu+1}{\nu\alpha}\). It follows that \(\bar z = \frac{\sigma}{\alpha^2\nu}(\alpha\nu-\nu -1)\) and \(\bar y = \frac{\sigma}{\alpha^2\nu^2}(\alpha\nu-\nu -1)\).

Note that the equilibrium is meaningful only when \(\bar x \ge 0\), \(\bar y \ge 0\), and \(\bar z \ge 0\). So when have the extra condition for \(E^+\) to exists: \[ (\alpha-1)\nu - 1\ge 0. \]

  1. Find the conditions for the stability of \(E_1\) and of \(E^+\). Note that there are parameter values such that all equilibria are unstable; if possible, use a computer to explore the bahaviour of solutions in such a case. Hint: use the Routh-Hurwitz criteria Theorem A.7 .
Solution

The Jacobian of the system is \[ J(x,y,z) = \left[\begin{matrix} \sigma (1-2x) & 0 & -\alpha x \\ \alpha z & -(\nu+1) & \alpha x \\ 0 & \nu & -1 \end{matrix}\right]. \]

For \(E_1\), we have: \[ J_1 = \left[\begin{matrix} -\sigma & 0 & -\alpha \\ 0 & -(\nu+1) & \alpha \\ 0 & \nu & -1 \end{matrix}\right], \]

which is block triangular. One eigenvalue is \(-\sigma < 0\). The other eigenvalues are those of the bottom-right \(2\times 2\) block. The trace of the block is always negative and the determinant is \((\nu+1)-\alpha\nu=(1-\alpha)\nu+1\), which is positive only when \(E^+\) does not exist. So, when \(\bar z < 0\), the block has eigenvalues with negative real part, hence the \(E_1\) is asymptotically stable, otherwise \(E_1\) is a saddle (dimension of the stable and unstable manifold are respectively \(n_S=2\) and \(n_U=1\)).

Concerning \(E^+\) we have \[ J^+ = \left[\begin{matrix} -\sigma\bar x & 0 & -\alpha\bar x \\ \sigma(1-\bar x) & -(\nu+1) & \alpha\bar x \\ 0 & \nu & -1 \end{matrix}\right]. \]

The stability is not trivial, as it requires the Routh-Hurwitz stability criterion. The characteristic polynomial is \[ \mathcal{P}(\lambda)=\lambda^3+ a_1 \lambda^2 + a_2 \lambda + a_3, \]

where \[ \begin{aligned}a_3 &= -\det J^+ = \sigma \bar x (1 + \nu + \alpha\nu - 2\bar x\nu \alpha), \\ a_2 &= (1 + \nu) +\bar x\alpha\nu + \bar x (2 + \nu)\sigma, \\ a_1 &= -\operatorname{tr} J^+ = 2 + \nu + \sigma\bar x. \end{aligned} \]

These numbers are (minus) the invariants of the matrix \(J^+\). The Routh-Hurwitz criterion for \(3\times 3\) matrices says that all the roots of \(\mathcal{P}(\lambda)\) have negative real parts if and only if \[ \begin{aligned}a_1 &> 0, \\ a_2 &> 0, \\ a_3 &> 0, \\ a_1a_2 &> a_3. \end{aligned} \]

We see that \[ \begin{aligned}a_1 &> 0, && \text{always}, \\ a_2 &> 0, && \text{always}, \\ a_3 &> 0, && \text{when $\alpha>1$ and $\nu > \frac{1}{\alpha-1}$}, \\ a_1a_2 &> a_3, && \text{depends on $\alpha$.} \end{aligned} \]

For the last condition, we see that for sufficiently large \(\alpha\) we have \(a_1a_2-a_3 \to -\infty\). On the other hand, for \(\bar x=1\) and so \(\alpha=\frac{1+\nu}{\nu}\) the quantity is positive. We conclude that there exists at least a point \(\alpha^*\) such that for \(\alpha > \alpha^*\) the quantity is negative. \(E^+\) is asymptotically stable for \(\frac{1+\nu}{\nu} < \alpha < \alpha^*\), and possibly unstable otherwise.

Green pools

It is often observed that, in the pools where fish have been added, water has a greenish colour, indicating a high algal biomass. Try to explain this using a prey-predator system, assuming that algae (prey)-zooplankton (predators) follow a Holling-type 2 predator-prey system, where prey grow according to the logistic equation and predators have mortality rate given by \(d + bF\) where \(F\) is fish density (assumed to be constant).

  1. Write down the model.
Solution

We use the variables \(A(t)\) and \(Z(t)\) for algae and zooplankton population, respectively. The general model reads: \[ \left\{ \begin{aligned} A' &= r(A)A - \pi(A)Z, \\ Z' &= Z(-\mu(Z) + \gamma\pi(A)). \end{aligned} \right. \]

With the assumptions, we have: \[ \begin{aligned} \pi(A) &= \frac{a A}{1+aT_h A}, \\ r(A) &= r(1-A/K), \\ \mu(Z) &= d+b F. \end{aligned} \]

  1. Find how equilbrium algal biomass and equilibrium stability vary with fish density \(F\), and comment the results.
Solution

The model fits the Gause modeling framework. The best strategy is to first non-dimensionalize. We can use: \[ x = \frac{A}{K},\quad z = \frac{Z}{\gamma K},\quad \tau = d t. \]

We obtain: \[ \left\{\begin{aligned} x' &= x\Bigl(\rho(1-x) + \frac{\alpha\delta z}{1+\delta x} \Bigr), \\ z' &= z\Bigl( -f + \frac{\alpha\delta x}{1+\delta x} \Bigr). \end{aligned}\right. \]

where the only interesting parameter is \(f\), which is proportional to \(F\). Specifically: \[ \rho = \frac{r}{d}, \quad \alpha = a T_h K,\quad \delta = \frac{\gamma}{d T_h}, \quad f = \frac{bF}{d}+1. \]

Two equilibria are always present: \(E_0 = (0,0)\) and \(E_1=(1,0)\). The positive equilibrium \(E_* = (x_*,z_*)\) follows from the isoclines: \[ \left\{ \begin{aligned} z &= \frac{\rho}{\alpha\delta}(1-x)(1+\delta x) = \phi(x), \\ x &= \frac{f}{\delta(\alpha-f)} = x_*. \end{aligned} \right. \]

We note that only \(x_*\) depends on \(f\), and hence the fish density \(F\) (linearly).

Before studying the function \(x_*(f)\), let us recall the equilibrium diagram with respect to \(x_*\).

  • \(x_* > 1\): \(E_1\) is globally stable, and \(E_*\) does not exist because \(z_* < 0\);
  • \(x_\mathrm{max} < x_*< 1\): \(E_*\) is globally stable, where \(x_\mathrm{max}=(\delta-1)/2\delta\) is the ascissa of the vertex of \(\phi(x)\), which does not depend on \(f\).
  • \(x_* < x_\mathrm{max}\): there is a unique, globally stable limit cycle around the (unstable) equilibrium \(E_*\).

Now we turn our attention to \(x_*(f)\). The function is increasing and has a vertical asymptote for \(f=\alpha\), so it is positive. Therefore, the intervals above for \(x_*\) are nicely mapped on interval for \(f\), as below.

Code 
import matplotlib.pyplot as plt
import numpy as np

rho = 1.0; alpha = 2.0; delta = 5

xstar = lambda f: f/(delta*(alpha-f))
f = np.linspace(0,alpha*0.9,1000)
xmax = (delta-1)/(2*delta)
f1 = delta*alpha/(1+delta)
f2 = delta*alpha*xmax/(1+delta*xmax)
plt.axvline(x=alpha,linestyle='--')
plt.axhline(y=1,color='r',linewidth=0.5)
plt.axhline(y=xmax,color='r',linewidth=0.5)
plt.axvline(x=f1,color='r',linestyle='--',linewidth=0.5)
plt.axvline(x=f2,color='r',linestyle='--',linewidth=0.5)
plt.plot(f,xstar(f),linewidth=2.0)
plt.xticks([0,f1,f2,alpha],['0','$f_1$','$f_2$','$\\alpha$'])
plt.yticks([1, xmax], ['1','$x_{max}$'])
plt.gca().spines.right.set_color('none')
plt.gca().spines.top.set_color('none')
plt.subplots_adjust(left=0.08, bottom=0.1, right=0.8, top=0.95, wspace=0, hspace=0)
plt.show()

For \(f > \alpha\) the function is negative, so the globally attractive equilibrium is \(E_1\). Hence, no zooplancton and high-level of algae. Similarly for \(f > f_1\), \(E_1\) is globally attractive. For \(f_2 < f < f_1\) the equilibrium \(E_*\) is globally attractive. Finally, for \(f < f_2\), there exists a unique limit cycle around \(E_*\).

In conclusion, the pond is greenish for \(f > f_1\). Note that for \(F=0\) (no fish population) we have \(f=1\), from which we recover the original Rosenzweig-MacArthur model.

  1. Assume now that the zooplankton mortality rate is \(d + \frac{bF}{1+cZ}\) where \(Z\) is zooplankton density (Holling-type 2 functional response). Study the equilbria of the system.
Solution

We can use the above non-dimensionalization and obtain \[ \left\{\begin{aligned} x' &= x\Bigl(\rho(1-x) + \frac{\alpha\delta z}{1+\delta x} \Bigr), \\ z' &= z\Bigl( -\frac{f + \eta z}{1+\eta z} + \frac{\alpha\delta x}{1+\delta x} \Bigr). \end{aligned}\right. \]

where we have \(\eta = c\gamma K\).

As above, two equilibria are always present: \(E_0 = (0,0)\) and \(E_1=(1,0)\). Other equilibria follow from the isoclines: \[ \left\{ \begin{aligned} z &= \frac{\rho}{\alpha\delta}(1-x)(1+\delta x) = \phi(x), \\ z &= \frac{f+(f-\alpha)x\delta}{\eta (\alpha-1)\delta x - \eta} = \psi(x). \end{aligned} \right. \]

The curve \(\phi(x)\) is a parabola as above. The curve \(\psi(x)\) is a branch of hyperbola. We have that: \[ \begin{aligned}\lim_{x\to \bar{x}^+} \psi(x) &= +\infty, \quad \bar x = \frac{1}{\delta(\alpha-1)} \\ \lim_{x\to\infty} \psi(x) &= \frac{f-\alpha}{\eta(\alpha-1)}.\end{aligned} \]

For \(0 \le x < \bar{x}\) the function \(\psi\) is negative. Moreover, \(\psi' > 0\) for \(f > 1\) (that is, \(F>0\)). The effect of reducing \(f\) is to lower the right endpoint of the curve \(z=\psi(x)\), thus potentially intersecting the other nullcline.

The most interesting case is when \(\bar{x}\) is to the left of \(x_\mathrm{max}\), which corresponds to the case of a unique limit cycle for \(F=0\). Here, we have 3 possible situations:

  1. \(1 \le f < f_1 = \frac{\delta\alpha}{\delta+1}\): one intersection, because \(\psi(x)\) becomes negative before \(x=1\), and thus the additional intersection would be biologically non-feasible. If the only intersection occurs at a point for \(\phi'(x)<0\), then we have a limit cycle, otherwise the equilibrium is asymptotically stable;
  2. \(f_1 < f < f_2\): two intersections, yielding two new equilibria \(E_*\) and \(E_{**}\). This case is much more complicated to study. Firstly, \(E_1\) is locally stable, meaning that depending it attracts some trajectories, depending on the initial conditions. The equilibrium \(E_{**}\) (we suppose it is the one on the right) is always a saddle. The equilibrium \(E_*\) is either asymptotically stable or unstable spiral, depending on its position. When it is unstable, it is surrounded by a limit cycle. For a specific range of \(f\), there is also a homoclinic orbit, corresponding to a limit cycle of infinite period.
  3. \(f > f_2\): no intersections, \(E_1\) is the only globally stable equilibrium, thus we have a greenish pool;

In conclusion, the pond is greenish when \(f\) is large, but it may happen also at some moderate value of \(f\), depending on the initial conditions.

Holling type 3 response

Consider the following prey-predator system: \[ \left\{\begin{aligned} H' &= H \Bigl( r(1-H/K)−\frac{a H P}{H^2 + \beta^2} \Bigr), \\ P' &= P \Bigl( -c + \frac{\gamma a H^2}{H^2 + \beta^2} \Bigr). \end{aligned}\right. \]

where all parameters are positive.

  1. Give a biological interpretation to these equations. Consider especially the functional response used in this model.
Solution

This is a Gause-type model with Holling type III functional response, logistic growth of the preys, and numerical response proportional to the functional response. A Holling type III response means that at low level of \(H\), predation is also low, whereas it significantly increases with maximum derivative at \(H=\beta\). For very large value of \(H\), the response tends to \(a\), the maximum killing rate.

  1. Find all equilibria (in the first quadrant) and study their stability for \(a\gamma < c\).
Solution

We always have 2 equilibria:

  • \(E_0=(0,0)\) and
  • \(E_K=(K,0)\).

An additional equilibrium \(E_*=(H_*,P_*)\) is present only when it is in the positive quadrant. Specifically we have \[ H_*^2 = \frac{c\beta^2}{\gamma a-c}, \]

thus \(H_*\) is well-defined only for \(\gamma a \ge c\). Hence, for \(a\gamma<c\) we only have 2 equilibria.

For the stability, we have the Jacobian: \[ J(H,P) = \left[ \begin{matrix} r(1-2H/K) - \pi'(H)P & -\pi(H) \\ \gamma\pi'(H)P & -c + \gamma\pi(H) \end{matrix}\right], \]

where \(\pi(H)\) is the functional response. Thus, we have \[ J_0 = J(0,0) = \left[ \begin{matrix} r & 0 \\ 0 & -c \end{matrix}\right], \]

from which we conclude that \(E_0\) is a saddle point. Moreover, \[ J_K = J(K,0) = \left[ \begin{matrix} -r & -\pi(K) \\ 0 & -c + \gamma\pi(K) \end{matrix}\right], \]

which has eigenvalues \(\lambda_1 = -r < 0\) and \(\lambda_2 = -c + \gamma\pi(K)\). The condition \(\lambda_2 < 0\) would ensure the stability of \(E_K\). Specifically, \[ -c + \gamma\pi(K) = -c + \gamma a\frac{K^2}{\beta^2 + K^2} < 0. \]

Since \(a\gamma < c\) by hypothesis, the right hand side is negative so \(E_K\) is always asymptotically stable.

  1. Assume \(a\gamma > c\). Find the conditions on \(K\) that make unstable the equilibrium without predators (but with a positive number of preys).
Solution

As we have seen above, for \(a\gamma>c\) the eigenvalue \(\lambda_2\) of \(J_K\) becomes positive when \(K^2 > H_*^2\) (note that the right hand side in the above inequality is exactly \(H_*^2\)), thus the condition on \(K\) is \(K > H_*\).

  1. Show that a positive equilibrium \((H^*,P^*)\), if it exists, is stable if \[ \frac{r}{K} + a P^*\phi'(H^*) > 0,\quad \phi(H) = \frac{H}{H^2+\beta^2}. \]

    Hint: to show this, it is convenient to rewrite the system using the function \(\phi\), and compute the positive equilibrium and the Jacobian through \(\phi(H^*)\) and \(\phi'(H^*)\), without explicitly computing these.

Solution

For \(E_*\) to exists, we need \(H_*> 0\) and \(P_*> 0\). The first condition is statisfied for \(\gamma a > c\). The second one, we have \[ P_* = \frac{r}{a H_*}(1-H_*/K)(H_*^2 + \beta^2) > 0, \]

which occurs for \(H_*< K\).

Note that \(a\phi(H)H = \pi(H)\), so \(aH\phi'(H)+a\phi(H)=\pi'(H)\). Thus, we can reuse \(J(H,P)\) as above. Substituting we have: \[ J_* = J(H_*,P_*) = \left[ \begin{matrix} r(1-2H_*/K) - \pi'(H_*)P_* & -\pi(H_*) \\ \gamma\pi'(H_*)P_* & -c + \gamma\pi(H_*) \end{matrix}\right]. \]

Note that \(-c+\gamma\pi(H)=0\) is a nullcline for \(P'=0\), so \(-c+\gamma\pi(H_*)=0\). Since \(\pi(H) > 0\), \(\pi(H)>0\), and \(P_*>0\), we have that \[ \det J_* = \pi(H_*)\gamma \pi'(H_*)P_* > 0. \]

So the equilibrium is not a saddle. By looking at the trace, the asymptotic stability is ensured when: \[ \operatorname{tr} J_* = r(1-2H_*/K) - \pi'(H_*)P_* < 0. \]

Since the non-trivial nullcline for \(H'=0\) indicates that \(r(1-H/K)−aP\phi(H)=0\), we obtain: \[ \operatorname{tr} J_* = -r/K - a P_*\phi'(H_*) < 0, \]

which is equivalent to the above condition.

  1. Show that the previous conditions is equivalent to \(\Phi'(H^*) < 0\), where \(\Phi(H) = \frac{r(1-H/K)(H^2+\beta^2)}{a H}\) is the function for the nullcline \(H'=0\), when \(P=\Phi(H)\).
Solution

We observe that \[ \Phi(H) = \frac{r(1-H/K)}{a\phi(H)}. \]

Therefore we have \[ a \Phi(H)\phi(H) = r(1-H/K), \]

thus, \[ a \Phi'(H_*) \phi(H_*) + a \Phi(H_*) \phi'(H_*) = -r/K. \]

Now, \(\Phi(H_*)=P_*\), and thanks to Q1.4 we obtain that: \[ a \Phi'(H_*) \phi(H_*) = -r/K - a P_*\phi'(H_*) < 0. \]

Since \(a\phi(H_*) > 0\), we conclude that \(\Phi'(H_*) < 0\). Viceversa, if \(\Phi'(H_*) < 0\) then the above condition holds. So they are equivalent.

  1. Scale the system by setting \(x = H/\beta\), \(y = P/(\gamma\beta)\), \(\tau = ct\). The resulting system should have only 3 parameters, that can be chosen as \(\eta = \beta/K\), \(\alpha = a\gamma/c\), \(\rho = r/c\).
Solution

After rewriting the previous conditions for the existence of a positive equilibrium in terms of the new parameters, study (with the help of a computer) how its stability changes as \(K\) increases, i.e. \(\eta\) decreases.

The system we obtain is: \[ \left\{\begin{aligned} H' &= x \Bigl( \rho (1-\eta x)− \alpha \frac{x y}{x^2 + 1} \Bigr), \\ P' &= y \Bigl( -1 + \alpha \frac{x^2}{x^2 + 1} \Bigr). \end{aligned}\right. \]

The condition on the existence of \(E_*\) is \(\gamma a > c\), so \(\alpha > 1\), and \(H_*< K\), hence \(\eta < \sqrt{\alpha-1}\). The stability of \(E_*\) is determined by the inequality \(\Phi'(H_*)< 0\). Since \(\Phi(H)\) was defined as the nullcline \(P=\Phi(H)\), we can change the variables and define \[ \tilde\Phi(x) = \frac{\rho(1-\eta x)(x^2+1)}{\alpha x}, \]

and the condition for the new system is \(\tilde{\Phi}'(x_*)<0\), that is \[ \tilde{\Phi}(x_*) = \rho \frac{x_*^2 - 1 - 2\eta x_*^3}{\alpha x_*^2} < 0. \]

Equivalently, the condition of stability is: \[ \eta > \bar\eta = \frac{x_*^2 - 1}{2 x_*^3} = (1-\alpha/2)\sqrt{\alpha-1}. \]

Thus, for \(\bar\eta < \eta < \sqrt{\alpha-1}\) the equilibrium \(E_*\) is stable. Note that for \(\alpha \ge 2\), the equilibrium is always stable, when there exists, because \(\bar\eta \le 0\).

As \(\eta\) decreases below the value of \(\bar\eta\), the equilibrium \(E_*\) becomes unstable. Since \(E_*\) is never a saddle, because \(\det J_* > 0\), the change of stability must occur with a change of sign of the real part of both the eigenvalues simultaneously, hence they are complex conjugate. We have a supercritical Hopf bifurcation for \(\eta=\bar\eta\).
